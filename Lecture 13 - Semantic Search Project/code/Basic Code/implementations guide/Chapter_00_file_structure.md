## Design principle: follow the notes' mental model

The notes (Chapter 06) describe a four-step pipeline:

```
REPRESENT  →  STORE  →  COMPARE  →  RANK
   (embed)     (save)   (score)   (sort + slice)
```

Every file under `src/` maps onto one (or two) of those steps:

- **REPRESENT** → `embedding.service.ts` (`EmbeddingService.embedText`)
- **STORE** → `vector.store.service.ts` (`VectorStoreService.addMovies`)
- **COMPARE / RANK** → `recommendation.service.ts` (`cosineSimilarity`, `search`, `similarTo`)
- **HTTP wiring** → `controllers/search.controller.ts` + `routes/search.routes.ts`
- **Boot** → `index.ts`

When you read a chapter, you'll see which step its code implements and how
it calls the layer below it — exactly the dependency direction the notes
enforce (HTTP → Services → embedding, never the reverse).
