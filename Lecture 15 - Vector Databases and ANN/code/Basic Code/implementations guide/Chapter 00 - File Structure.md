# Chapter 00 — File Structure

Before writing any code, understand where every file lives and why.

## 00.1 Full File Tree

```
code/Basic Code/
├── .env                         # Environment variables (PORT, NODE_ENV)
├── package.json                 # npm dependencies and scripts
├── package-lock.json            # Locked dependency versions (generated by npm install)
├── tsconfig.json                # TypeScript compiler configuration
├── src/
│   ├── index.ts                 # Express app entry point — starts the HTTP server
│   ├── config/
│   │   └── config.ts            # Reads .env, exports config object (port, nodeEnv)
│   ├── types/
│   │   └── index.ts             # TypeScript interfaces: VectorRecord, SearchResult, VectorFilter
│   ├── services/
│   │   └── vectorService.ts     # In-memory vector store: add(), search() with cosine similarity + filter
│   ├── controllers/
│   │   └── vectorController.ts  # Express route handlers: addVector, searchVectors, getCount
│   └── routes/
│       └── index.ts             # Express router — wires URLs to controller methods
└── implementations guide/       # This folder — chapter-by-chapter explanation of the code
```

## 00.2 Folder Responsibilities

| Folder | Responsibility |
|--------|----------------|
| `config/` | Reads environment variables from `.env` and exports a typed config object. Single source of truth for runtime settings. |
| `types/` | TypeScript interfaces shared across the app. No runtime logic — only types. |
| `services/` | Business logic. The `VectorService` class owns the vector data, similarity math, and filtering. |
| `controllers/` | Thin Express handlers. Parse `req.body`, call the service, send `res.json`. No business logic. |
| `routes/` | Express `Router`. Maps HTTP methods + paths to controller methods. |
| `index.ts` | Bootstraps Express, applies middleware (`cors`, `express.json`), mounts routes, starts listening. |

## 00.3 Commands to Run This Code

```bash
# 1. Install dependencies (creates package-lock.json and node_modules/)
npm install

# 2. Type-check without emitting
npx tsc --noEmit

# 3. Build to dist/
npm run build

# 4. Run in development (ts-node)
npm run dev

# 5. Run compiled output
npm start
```

## 00.4 How Data Flows (High Level)

```
Client → POST /api/vectors  → routes/index.ts → VectorController.addVector
                                     → VectorService.add() → stored in memory[]

Client → POST /api/search   → routes/index.ts → VectorController.searchVectors
                                     → VectorService.search() → cosine similarity over all vectors → top-K results
                                     → filter by payload if provided
```
