## 🎯 Overview

**Lecture 18** explores advanced RAG architectures that go beyond traditional vector-based retrieval. The focus is on **hierarchical knowledge systems** that preserve document structure while maintaining retrieval efficiency.

### Key Topics Covered

- **Traditional Vector RAG** limitations and challenges
- **Vectorless RAG** with hierarchical tree indexing
- **Agentic Tree Search** using LLMs as navigation agents
- **LLM Wiki architecture** for knowledge organization and management
- **Two-pass retrieval** strategies for cost-efficient querying
- **System comparisons** across Vector RAG, Vectorless RAG, and LLM Wiki
- **Production architectures** for enterprise-scale deployments

### Learning Objectives

✅ Understand the problems with traditional Vector RAG approaches
✅ Master the concept and implementation of Vectorless RAG
✅ Learn how Agentic Tree Search enables intelligent document navigation
✅ Build understanding of LLM Wiki for knowledge management
✅ Master Two-Pass Retrieval for cost-efficient querying
✅ Compare and choose the right architecture for different use cases
✅ Design production-ready hybrid RAG systems
