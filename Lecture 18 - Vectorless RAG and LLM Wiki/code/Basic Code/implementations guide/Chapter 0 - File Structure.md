# Chapter 0 — File Structure

> This chapter explains the complete project file structure. Every file's purpose and its role in the Vectorless RAG / LLM Wiki implementation is described below.

## Project Root

```
code/Basic Code/
├── .env                              # Environment variables (PORT, NODE_ENV, MAX_TREE_DEPTH, LLM_MODEL)
├── package.json                      # Node.js project metadata + dependencies (express, dotenv, typescript, ts-node, @types/*)
├── package-lock.json                 # Auto-generated by npm install (locks dependency versions)
├── tsconfig.json                     # TypeScript compiler configuration (target ES2020, module commonjs, strict)
├── src/
│   ├── app.ts                        # Express application entry point (server setup + route mounting)
│   ├── config/
│   │   └── config.ts                 # Central configuration (loads .env, exports config object)
│   ├── types/
│   │   └── index.ts                  # TypeScript interfaces (TreeNode, CatalogEntry, TreeSearchResult, TwoPassResult)
│   ├── services/
│   │   ├── treeIndexingService.ts    # Vectorless RAG: builds hierarchical document tree index
│   │   ├── agenticTreeSearchService.ts # Vectorless RAG: LLM navigates the tree to find relevant nodes
│   │   ├── wikiService.ts            # LLM Wiki: ingest files into vault, manage catalog, read content
│   │   └── twoPassRetrievalService.ts # LLM Wiki: Pass 1 scan catalog, Pass 2 load selected full content
│   ├── controllers/
│   │   ├── treeController.ts         # Express route handlers for /tree/build and /tree/search
│   │   └── wikiController.ts         # Express route handlers for /wiki/ingest, /wiki/catalog, /wiki/search
│   └── routes/
│       └── index.ts                  # Express route definitions (wires controllers to endpoints)
└── implementations guide/            # This folder — chapter-wise implementation guide
```

## Command to Create Structure

```bash
# From the Basic Code folder
mkdir -p src/config src/types src/services src/controllers src/routes "implementations guide"
```

## How the Files Connect

```
Request (HTTP) 
    ↓
src/app.ts (Express app, JSON parsing, health check, mount /api routes)
    ↓
src/routes/index.ts (route definitions)
    ↓
src/controllers/* (route handlers — business logic orchestration)
    ↓
src/services/* (core logic — tree indexing, agentic search, wiki, two-pass retrieval)
    ↓
src/types/index.ts (shared TypeScript interfaces)
    ↓
src/config/config.ts (central env configuration)
```
