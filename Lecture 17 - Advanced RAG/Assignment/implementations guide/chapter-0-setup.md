## 0.2 Files

### package.json
```json
{
  "name": "lecture-17-advanced-rag-basic",
  "version": "1.0.0",
  "description": "Basic Advanced RAG implementation (TypeScript + Express) for Lecture 17",
  "main": "dist/index.js",
  "scripts": {
    "build": "tsc",
    "start": "node dist/index.js",
    "dev": "ts-node src/index.ts"
  },
  "dependencies": {
    "dotenv": "^16.4.5",
    "express": "^4.19.2"
  },
  "devDependencies": {
    "@types/express": "^4.17.21",
    "@types/node": "^20.12.7",
    "ts-node": "^10.9.2",
    "typescript": "^5.4.5"
  }
}
```

**Block-by-block:**
- `name` / `version` / `description` — package identity.
- `main` — entry point after build (`dist/index.js`).
- `scripts.build` — compiles TypeScript to JavaScript.
- `scripts.start` — runs the compiled server.
- `scripts.dev` — runs TypeScript directly with `ts-node` (no build step).
- `dependencies` — `express` (web framework), `dotenv` (loads `.env`).
- `devDependencies` — TypeScript, type definitions for express/node, `ts-node` for running TS directly.

### tsconfig.json
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true,
    "declaration": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

**Block-by-block:**
- `target: ES2020` — compile to modern JavaScript.
- `module: commonjs` — Node.js module format (required by `ts-node`/`express`).
- `outDir` / `rootDir` — output goes to `dist/`, source stays in `src/`.
- `strict: true` — enables all strict type checks (helps catch bugs early).
- `esModuleInterop` — allows importing CommonJS modules with default imports.
- `include` / `exclude` — only compile `src/`, skip `node_modules` and `dist`.

## 0.3 Commands

```bash
# 1. Install dependencies
npm install

# 2. Type-check without emitting
npx tsc --noEmit

# 3. Run in development (ts-node, no build)
npm run dev

# 4. Build then start
npm run build
npm start
```

**Expected output:**
```
Advanced RAG server running on http://localhost:3000
Environment: development
POST http://localhost:3000/rag/query
```

Test it:
```bash
curl -X POST http://localhost:3000/rag/query \
  -H "Content-Type: application/json" \
  -d '{"query":"Can I return my damaged headphones after 10 days?"}'
```
