## 6.3 Full code — src/services/artifact.service.ts

```ts
import { store } from "../store/memory-store";

export async function generateArtifacts(conversationId: string, workspaceId: string, userId: string) {
  const conversation = store.getConversation(conversationId);
  if (!conversation) throw new Error("Conversation not found");

  const assistantTexts = conversation.messages.filter((m) => m.role === "ASSISTANT").map((m) => m.content);
  const joined = assistantTexts.join(" ");

  const flashcard = {
    type: "FLASHCARD" as const,
    front: "What is the key takeaway from this conversation?",
    back: joined.slice(0, 200),
    tags: ["conversation"],
    difficulty: "EASY" as const,
  };
  const quiz = {
    type: "QUIZ" as const,
    questions: [{ id: "q1", question: "Summarize the discussion in one sentence.", options: [], answer: joined.slice(0, 100) }],
  };
  const summary = { type: "SUMMARY" as const, summary: joined.slice(0, 500) };

  const artifacts = [flashcard, quiz, summary];
  for (const a of artifacts) {
    store.createArtifact({ ...a, conversationId, workspaceId, userId, content: a });
  }
  return artifacts;
}
```

## 6.4 Block-by-block explanation

| Block | What it does |
|-------|--------------|
| Read conversation | Loads the conversation and collects assistant messages. |
| Build artifacts | Creates one `FLASHCARD` (Q&A), one `QUIZ` (MCQ-style), one `SUMMARY` from the conversation text. |
| Persist | Saves each artifact via `store.createArtifact` so the frontend can list/render them per conversation. |

## 6.5 How it works

Turns a finished conversation into structured study resources. In production these would be generated by the LLM (with validation to avoid hallucinations, per the notes) and triggered periodically or at conversation end.
