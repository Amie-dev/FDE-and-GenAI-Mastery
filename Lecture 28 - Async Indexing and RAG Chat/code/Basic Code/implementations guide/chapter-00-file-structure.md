# Chapter 0: File Structure & Setup

## 0.1 Folder structure (created in this chapter)

```
code/Basic Code/
├── .env
├── package.json
├── package-lock.json        (generated by npm install)
├── tsconfig.json
└── src/
    ├── config/
    │   └── config.ts        # env config (PORT, API keys)
    ├── controllers/
    │   ├── source.controller.ts   # sources CRUD + reprocess + chunks (Ch 1, 2)
    │   ├── chat.controller.ts     # SSE chat stream (Ch 3)
    │   ├── citation.controller.ts # chunk preview API (Ch 4)
    │   └── job.controller.ts      # job CRUD + status SSE (Ch 7)
    ├── routes/
    │   └── index.ts             # mounts all /api routes
    ├── services/
    │   ├── indexing.service.ts    # chunking + embed + upsert (Ch 1)
    │   ├── source.service.ts      # PENDING→PROCESSING→READY/FAILED (Ch 2)
    │   ├── chat.service.ts        # RAG retrieval + SSE stream (Ch 3)
    │   ├── citation.service.ts    # citation build + preview (Ch 4)
    │   ├── memory.service.ts      # Mem0 stub (Ch 5)
    │   ├── web-search.service.ts  # Tavily stub (Ch 5)
    │   ├── artifact.service.ts    # flashcards/quiz/summary (Ch 6)
    │   └── job.service.ts         # job status CRUD (Ch 7)
    ├── store/
    │   └── memory-store.ts    # in-memory store (runs without DB/keys)
    ├── types/
    │   └── index.ts           # shared TS types
    ├── app.ts                 # express app
    └── server.ts              # entry point (listen)
```

## 0.2 Commands to run

| Purpose | Command |
|---------|---------|
| Install dependencies (creates package-lock.json) | `npm install` |
| Type-check | `npx tsc --noEmit` |
| Run dev server | `npm run dev` |
| Build | `npm run build` |
| Start production | `npm start` |

Server listens on `http://localhost:4000` (PORT from `.env`). Health check: `GET /health`.

## 0.3 Design notes (keep it minimal)

- No database, Pinecone, Inngest, Mem0, or Tavily keys required to run — `src/store/memory-store.ts` is an in-memory store and the AI services are stubs with comments showing where to plug the real packages.
- One file per feature, following the `controllers → routes → services` layout from the notes.
- Relevant packages from `package.json`: `express`, `cors`, `dotenv`, `zod`, `uuid`, `ts-node`, `typescript`.
